# Glossary

- **Collection segment** — the second segment of a gallery attachment path, for example `faq_images` in `/attachments/gallery/faq_images/<id>/thumb`, which `Gallery::Image::ATTACHMENT_SEGMENTS` maps to one image type.
- **Dice mechanic** — the value of a dice-mechanic field: a dice expression such as `1d20+2d6`, or `Standard`, `Fate` or `Roll Under`, and nothing else around it.
- **Image type** — the STI `type` value of a `Gallery::Image` row, for example `"Gallery::FaqImage"`.
