- [x] Important: The form refuses every attack on a built 4e monster that has no usage. The usage select has a blank option, so the form submits `power_usage: ""`; the inclusion check allows only `nil`, so the save fails with "is not included in the list" (reproduced: `Attack.new(..., power_usage: "")` is invalid). This also blocks editing every existing attack on a built monster (phase B's `monster_greataxe`), because `nil` → `""` counts as a change. The plan keeps usage blank until chosen. The unit test checks `power_usage: nil` only, and every integration and system test picks a usage, so no test sends the real form value. — `engines/entitybuilder/app/models/entitybuilder/attack.rb:38` → fixed (Treat a blank power usage as none on an attack)
- [x] Important: Changing the action type, or ticking "recharges when first bloodied", overwrites a hand-edited attack bonus and damage. The change handler listens to every select and input in `#power_fields`, but plan design decision 3 prefills only on usage, multi-target and usable-at-will. A GM who edits damage to 20 and then picks "Minor" gets the prefill again with no warning. — `engines/entitybuilder/app/views/entitybuilder/attacks/_form.html.erb:124` → fixed (Prefill power numbers only when usage, multi-target or usable at will change)
- [x] Important: A marked power cannot change its usage after a group change. Plan decision 5 keeps the mark stored when an Elite becomes a Standard (or a Solo becomes an Elite), and the form then hides that mark's checkbox. If the GM changes the usage, the mark validation runs and refuses the save ("needs an Elite monster", reproduced on `elite_marked_power`), and the GM has no checkbox to clear the mark. Only deleting the power gets out. — `engines/entitybuilder/app/models/entitybuilder/attack.rb:40` → fixed (Let the GM clear a stored power mark after a group change)

The entity could answer `monster_elite?` and `monster_solo?`, so the attack and the view tell instead of ask. — `engines/entitybuilder/app/models/entitybuilder/attack.rb:55` → fixed (Ask the entity whether it is an Elite or a Solo)
